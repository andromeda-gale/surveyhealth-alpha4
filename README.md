# surveyhealth-alpha4

| What is... | Response |
|:---:|:---:|
| **App Name** | SurveyHealth |
| **Purpose** | Mood Tracker with Psychologist/Psychiatrist contact functionality. |
| **Page 1 - Name & Description** | Home Page - Includes text field for email and password, acting as a log in. It has the phrase "Welcome to SurveyHealth!" At the top in large and bold, with the greek letter Psi (for psychology) just below. |
| **Page 2 - Name & Description** | Landing Page – Calendar, profile overview, and settings. Has a drop-down menu for other pages, including FAQ, Contact Us, and Log Out. Has two buttons to link to the EXPORT and SURVEY pages. Has setting functionality for font size, high contrast, and more. |
| **Page 3 - Name & Description** | Survey Page – A page where users can input responses to evaluate their emotions for the day/week/month based on a series of questions, including a value range (1 to 10) and additional input fields for additional information. |
| **Page 4 - Name & Description** |Contact Us Page – Page with a built-in format to contact our team to report issues, as well as answer questions.  |
| **Page 5 - Name & Description** | Export page – A page that can create a file summary of data and export that summary as a pdf. This page can also send that summary to trusted individuals. The page creates a preview of the exporting file for user reference.  |
| **Page 6 - Name & Description** | Frequently Asked Questions Page - Page where users go for their frequently asked questions, accordion type set up for these questions, that way users can get answers for common questions without having to use the contact us page |
| **Key Interactive Feature 1** | A login page with traditional email/password login functionality and SSO functionality.  |
| **Key Interactive Feature 2** | An interactable calendar that, on hover, enlarges the date and, on click, allows one to review their survey for that day. |
| **Key Interactive Feature 3** | Interactable buttons that log how a user feels on a range of 1 to 10 with an additional text box to log anything particular that relates to the question. |
| **Key Interactive Feature 4** | Interactable box in that you can send emails with, as well as the hamburger |
| **Key Interactive Feature 5** | Checkable boxes that specify what to include in a file summary for user data.  |
| **Key Interactive Feature 6** | This page will have a functional accordion for users to click and reveal answers to common questions, as well as have access to the hamburger   |
